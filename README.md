# Estação meteorológica IOT
Projeto desenvolvido para apresentação na 25ª edição do Congresso de Iniciação Científica e Pesquisa (CONIC) da Universidade de Ribeirão Preto.
Tem como objetivo obter informações de temperatura, pressão, umidade, preciptação, velocidade do vento, quantidade de CO2 em ppm e demonstrar, graficamente, o histórico das medidas.
As informações são enviadas para o RealTime Database do Firebase e, posteriormente, exibidas em um aplicativo desenvolvido com o framework Flutter.
